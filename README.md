# Capstone_1
This repository includes information regarding sales for EmporiUm, particularly sales in Colorado. In this repository, you will find the MySQL script that I used to find information on online and in store sales in Colorado. I also used this script to see which categories are our best-selling category and to see the performance of the physical stores in Colorado. 
You will also find an Excel workbook that I used to create several pivot charts to help visualize the data, so the audience can have an easier time understanding the data and what it means.
